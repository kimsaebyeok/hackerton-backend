🔗 한눈에 보는 데이터 흐름

  • 이벤트 7·9·12·14번(admin↔sheets 탭 전환) → repeatedCycles.occurrences = 3 → 카드 근거 반복 왕복 3회
  • 이벤트 3·6·8·11·13·15번(dwell) → timeByDomain 합산 → 세션 내 소요 4.4분 → est_saving_min_day 환산
  • 이벤트 5·10번(같은 "셀 입력" 클릭) → repeatedClicks.count = 2 → inputsObserved.repeated_action
  • 입력값을 안 받음 → missingContext의 data_mapping 질문으로 자동 전환 → ⑥에서 유저가 채움

→ 즉 raw 18줄이 추천 1건으로 압축되는 전 과정이 테이블에 그대로 남습니다.
